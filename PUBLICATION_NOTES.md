# Publication notes

This archive contains AnkiLink v2.0.11 client code, the Python server, tests, and selected project documentation. It excludes packaged builds, deployment snapshots, and duplicated historical hosted-server copies.

Before publishing:
- Review all configuration, URLs, and source comments for information you do not want public.
- Rotate any access tokens or invitation codes used in an earlier deployment if they might have been shared.
- Add an open-source license only if you have the rights to license all included material.
- Verify supported Anki versions and run the test suite in your own environment.

The README describes multiple features, but this packaging review does not independently test live services or guarantee deployment compatibility.
